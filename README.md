# موقع معهد هدى للناس (نسخة بخادم وقاعدة بيانات)

بدون أي مكتبات خارجية — يلزم فقط **Python 3.8+**.

## التشغيل
```bash
python server.py
```
ثم افتح http://localhost:8000
عند أول تشغيل تُنشأ قاعدة البيانات `mahad.db` وتُملأ ببيانات الموقع، ويُنشأ حساب المشرف الأول وتُطبع بيانات دخوله مرة واحدة. الحساب يحصل على صلاحيات كاملة لإدارة الموقع.
لتحديد بياناته بنفسك: `ADMIN_USER=admin ADMIN_PASS=كلمة_قوية python server.py` (قبل أول تشغيل).
نسيت كلمة المرور؟ `python server.py setpass admin كلمة_جديدة`

## معاينة الموقع مع العميل
- على نفس الجهاز: افتح `http://localhost:8000`.
- على شبكة Wi-Fi واحدة: افتح الموقع على جهاز التشغيل بعنوان الشبكة المحلي والمنفذ `8000`، بعد السماح للمنفذ في جدار حماية Windows.
- من مكان آخر: انشر الموقع على استضافة HTTPS عامة قبل مشاركة الرابط. لا تشارك رابط `localhost`؛ فهو يعمل على جهازك فقط. احتفظ بنسخة احتياطية من قاعدة البيانات والملفات المرفوعة، ولا تشارك بيانات المشرف.

زر الشمس/القمر في الشريط يبدّل بين الوضعين الفاتح والداكن ويحفظ اختيار الزائر على جهازه. تظهر صورة الشيخ في الواجهة الرئيسية وشعار الشريط وأيقونة التبويب، ويربط زر الشريط بقناة الشيخ على تيليجرام. بعد تسجيل الدخول تظهر قائمة للحساب تتضمن الملف الشخصي وتسجيل الخروج. رابط «تعرّف على البرامج» ينقل مباشرةً إلى قسم البرامج في الصفحة الرئيسية.

أُعيد تصميم الواجهة العامة ولوحة التحكم بخط Cairo، وألوان الأزرق الملكي وElectric Indigo والأبيض، مع دعم الشاشات الصغيرة والوضع الداكن.

## نماذج التصميم واستيرادها إلى Figma
الملف `static/mahad-redesign.svg` لوحة جامعة، والملفات `static/mahad-redesign-home.svg` و`static/mahad-redesign-program.svg` و`static/mahad-redesign-lessons.svg` و`static/mahad-redesign-dashboard.svg` شاشات منفصلة بخط Cairo. توجد ملفات مقابلة تنتهي بـ `-tajawal.svg` لمقارنة خط Tajawal. الصور مضمّنة داخل SVG؛ اسحب الشاشات المنفصلة إلى Figma لمراجعتها وتعديلها.

## ربط فيديوهات يوتيوب (لتعمل داخل الموقع)
1. ادخل بحساب المشرف ← **لوحة التحكم ← الفيديوهات**.
2. افتح الدرس (أو أضف جديدًا) والصق رابط يوتيوب:
   - قائمة تشغيل: `https://www.youtube.com/playlist?list=PL...`
   - فيديو: `https://www.youtube.com/watch?v=...` أو `https://youtu.be/...`
3. احفظ — يفتح الدرس فورًا في نافذة مشغّل داخل الموقع (youtube-nocookie) دون مغادرته.
الدروس الثمانية الأولية موجودة بعناوينها وصورها لكن **بلا روابط**، وتظهر بعلامة «قريبًا» حتى تربطها.

## التسجيل والنوع
يختار الطالب «ذكر» أو «أنثى» أثناء إنشاء الحساب. تُحفظ القيمة في حسابه وتُرفق بسجل الصادر عند إرساله إلى البرنامج، وتظهر للمشرفين ضمن قائمة الطلاب والصادر. تضاف أعمدة النوع تلقائيًا عند تشغيل الخادم على قاعدة بيانات موجودة.

## ما الذي في قاعدة البيانات (SQLite)
`settings` (نصوص الموقع وروابطه) · `programs` + `program_axes` + `program_plan` · `faqs` · `videos` ·
`users` (مشرف/طالب، كلمات المرور مشفّرة PBKDF2) · `sessions` · `enrollments` (طلب/اعتماد) ·
`supervisor_programs` · `saved_videos` · `outbox` (الصادر إلى البرامج) · `messages` (رسائل التواصل).

## الصلاحيات
- **زائر**: يتصفح، يشاهد الدروس، يرسل رسالة تواصل، ينشئ حسابًا.
- **طالب**: حسابه، طلب الانضمام لبرامج، حفظ الدروس، تعديل بياناته وكلمة مروره.
- **مشرف**: صلاحيات كاملة على الموقع — الطلاب، المشرفون، الرسائل، الفيديوهات، البرامج والمحاور والخطط، الأسئلة، الصادر، الإعدادات.

تُحوّل حسابات المدير القديمة تلقائيًا إلى مشرفين مع الاحتفاظ ببيانات الدخول، وتُمنح جميع حسابات المشرفين صلاحيات كاملة. لا يستطيع المشرف حذف حسابه بنفسه.

## النشر
- شغّله خلف HTTPS (nginx/Caddy) وفعّل: `SECURE_COOKIE=1 TRUST_PROXY=1`.
- المتغيرات: `PORT` (8000) · `HOST` (0.0.0.0) · `DB_PATH` (مسار قاعدة البيانات).
- النسخ الاحتياطي: انسخ ملف `mahad.db` ومجلد `static/uploads/`.
- **معاينة على Render:** افتح [لوحة Render](https://dashboard.render.com/blueprint/new?repo=https://github.com/mustafanasr3/mahad-elsheikh-hussien) بعد رفع المستودع، وراجع الإعدادات ثم أنشئ الخدمة. ينشئ Render كلمة مرور المشرف تلقائيًا؛ اعرضها من متغير `ADMIN_PASS` في إعدادات الخدمة. الخطة المجانية تستخدم تخزينًا مؤقتًا، لذلك قد تُمسح قاعدة البيانات والملفات المرفوعة عند إعادة تشغيل الخدمة أو نشر تحديث. لا تستخدمها لبيانات حقيقية أو دائمة؛ يلزم تخزين دائم ونسخ احتياطية لذلك.
